Bibliothèque publique

Un point d’entrée clair pour les documents et informations utiles

Cette page sert de porte d’entrée pour les ressources publiques du CGBVRR. Elle peut regrouper les documents vulgarisés, les liens vers les cartes, les ressources de partenaires et les publications pertinentes.

L’objectif est de garder les ressources lisibles pour le public sans exposer de données sensibles, d’emplacements à risque ou de documents qui doivent rester internes.
