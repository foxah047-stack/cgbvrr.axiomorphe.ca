This page serves as an entry point for CGBVRR public resources. It can gather plain-language documents, map links, partner resources and relevant publications.Cette page sert de porte d’entrée pour les ressources publiques du CGBVRR. Elle peut regrouper les documents vulgarisés, les liens vers les cartes, les ressources de partenaires et les publications pertinentes.

The goal is to keep resources readable for the public without exposing sensitive data, at-risk locations or documents that should remain internal.L’objectif est de garder les ressources lisibles pour le public sans exposer de données sensibles, d’emplacements à risque ou de documents qui doivent rester internes.
